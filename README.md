## 📌 Project Description
The **Data Analyzer and Transformer Program** is a menu-driven Python console application that allows users to input, analyze, filter, sort, and calculate statistics from a one-dimensional dataset. It also includes factorial calculation using recursion.

## 🎯 Objectives
- To understand and implement Python functions.
- To work with one-dimensional arrays using Python lists.
- To calculate minimum, maximum, sum, and average values.
- To calculate factorial using recursion.
- To filter data using lambda functions and `filter()`.
- To sort data in ascending and descending order.
- To practice loops, conditions, and `match-case`.
- To develop an interactive menu-driven Python program.
- To improve problem-solving and logical programming skills.

## 🚀 Features

1. **Input Data** – Accepts integer values separated by spaces.
2. **Display Summary** – Shows total elements, maximum, minimum, sum, and average.
3. **Calculate Factorial** – Calculates factorial using recursion.
4. **Filter Data** – Displays values greater than the entered threshold using `lambda` and `filter()`.
5. **Sort Data** – Sorts the dataset in ascending or descending order.
6. **Dataset Statistics** – Displays minimum, maximum, sum, and average.
7. **Exit** – Closes the program.

## ▶️ How to Run

1. Install Python 3.10 or above.
2. Open the project folder in VS Code.
3. Save the Python code in a file, for example:

```text
data_analyzer.py
```

4. Open the terminal and run:

```bash
python data_analyzer.py
```
